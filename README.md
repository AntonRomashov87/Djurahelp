# Джура — постійний бот (Telegram + Render)

Працює цілодобово: нагадування, тривоги, ранковий звіт, вечірній підсумок, посилки,
команди й голосові в Telegram. Ключі бере з налаштувань Джури у Firebase.

## Запуск (один раз)

1. **Ключ доступу до Firebase Джури.**
   Firebase Console → проєкт `djura-helper` → ⚙️ Project settings → Service accounts →
   Generate new private key. Завантажиться JSON-файл. Нікому його не показуй.

2. **GitHub.** Створи новий приватний репозиторій `dzhura-bot` і завантаж туди
   `bot.py`, `requirements.txt`, `render.yaml` (кнопка «Add file → Upload files»).

3. **Render.** New → Blueprint → вибери репозиторій `dzhura-bot` → Apply.
   Render попросить дві змінні:
   - `FIREBASE_SA_JSON` — встав увесь вміст JSON-файлу з кроку 1;
   - `PULT_PASSWORD` — пароль від Пульта (пошта береться з налаштувань Джури).

4. Через 2–3 хвилини бот напише тобі в Telegram «🛡️ Джура на посту».

5. **Щоб не засинав.** Бот сам себе будить кожні 5 хвилин. Для надійності додай
   безкоштовне завдання на cron-job.org: адреса `https://<твій-сервіс>.onrender.com/health`,
   кожні 5 хвилин. Воно ж напише тобі, якщо бот упаде.

## Що треба мати в налаштуваннях Джури (сайт)
- Вхід через Google (синхронізація), токен бота й Chat ID у розділі Telegram;
- ключ Gemini (лише для голосових і складних питань);
- за бажанням: токен тривог, ключ Нової Пошти, пошта від Пульта, час ранкового звіту.
