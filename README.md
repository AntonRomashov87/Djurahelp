# Джура — постійний бот (Telegram + Render)

Працює цілодобово: нагадування, тривоги, ранковий звіт, вечірній підсумок, посилки,
команди й голосові в Telegram. Ключі бере з налаштувань Джури у Firebase.

## Запуск (один раз)

1. **Ключ доступу до Firebase Джури.**
   Firebase Console → проєкт `djura-helper` → ⚙️ Project settings → Service accounts →
   Generate new private key. Завантажиться JSON-файл. Нікому його не показуй.

2. **GitHub.** Створи новий приватний репозиторій `dzhura-bot` і завантаж туди
   `bot.py`, `requirements.txt`, `render.yaml` (кнопка «Add file → Upload files»).

3. **Render.** New → Blueprint → вибери репозиторій `dzhura-bot` → Apply.
   Render попросить дві змінні:
   - `FIREBASE_SA_JSON` — встав увесь вміст JSON-файлу з кроку 1;
   - `PULT_PASSWORD` — пароль від Пульта (пошта береться з налаштувань Джури);
   - `TRACKER_PASSWORD` — пароль від трекера (потрібен лише після закриття його бази; пошта береться з налаштувань Джури, розділ «Трекер життя (вхід)»). Можна лишити порожнім, поки база відкрита.

4. Через 2–3 хвилини бот напише тобі в Telegram «🛡️ Джура на посту».

5. **Щоб не засинав.** Бот сам себе будить кожні 5 хвилин. Для надійності додай
   безкоштовне завдання на cron-job.org: адреса `https://<твій-сервіс>.onrender.com/health`,
   кожні 5 хвилин. Воно ж напише тобі, якщо бот упаде.

## Що треба мати в налаштуваннях Джури (сайт)
- Вхід через Google (синхронізація), токен бота й Chat ID у розділі Telegram;
- ключ Gemini (лише для голосових і складних питань);
- за бажанням: токен тривог, ключ Нової Пошти, пошта від Пульта, час ранкового звіту.

## Кнопки, нагадування, календар (v2)

- Напиши боту `/menu` (або «меню») — з'являться кнопки: звіт, план, звички, платежі, авто, погода, тривога, курс, календар, посилки, бекап, підсумок тижня.
- О 20:00 бот нагадує про невідмічені звички кнопками (змінити час: `habitRemindTime` у налаштуваннях або змінна `HABIT_TIME`; `off` вимикає).
- Щонеділі о 20:30 приходить підсумок тижня й файл резервної копії (без ключів і паролів). Час: змінна `WEEKLY_TIME`.
- Якщо щось ламається (Gemini, трекер, календар, фоновий цикл) — бот сам пише «⚠️», не частіше ніж раз на кілька годин.
- **Календар.** Відкрий Google Календар → налаштування свого календаря → «Надати доступ окремим людям» → додай пошту сервісного акаунта (поле `client_email` у JSON з `FIREBASE_SA_JSON`) з правом «Перегляд усіх подробиць подій». На Render додай змінну `CALENDAR_ID` — пошту, до якої належить календар. Бот нагадає про подію за годину й за 10 хвилин.


## Домашнє керування (лампи, ТВ)
Потрібна змінна **HOME_KEY** на Render і програма `home_agent` на планшеті вдома (див. `home_agent/README.md`). Без неї кнопки «Світло/Телевізор» просто скажуть, що планшет не на зв'язку.

## Здоров'я з годинника (/api/health)
Той самий `HOME_KEY`. Дані кладе будь-який міст:
```
curl -X POST https://<бот>.onrender.com/api/health -H "Content-Type: application/json" \
  -d '{"key":"<HOME_KEY>","steps":4441,"kcal":228,"km":3.47,"sleep_h":7.5,"hr_avg":72}'
```
Поля: steps, kcal, km, sleep_h, hr_avg, hr_rest, spo2, water; `date` (YYYY-MM-DD) необов'язкове.
У Джурі: «скільки я пройшов кроків», «як я спав за тиждень», «запиши кроки 5000».

## Пошта ukr.net — сповіщення про нові листи
На Render додай змінні: **MAIL_USER** (адреса, наприклад `anton@ukr.net`) і **MAIL_PASS**.
1. На ukr.net: Налаштування → «Поштові програми» (IMAP) → увімкни доступ по IMAP.
2. Створи **пароль для зовнішніх програм** і встав його в MAIL_PASS (основний пароль не використовуй).
3. Необов'язково: `MAIL_HOST` (за замовчуванням `imap.ukr.net`; для Gmail — `imap.gmail.com` + пароль застосунку), `MAIL_EVERY` (секунд між перевірками, мін. 60, за замовч. 120), `MAIL_IGNORE` (шматки адрес/імен через кому, які не показувати).
Бот читає лише заголовки (відправник, тема), листи не позначає прочитаними. Нові листи приходять у Telegram, а Джура в браузері повідомляє голосом (відправник) і на екрані (відправник + тема): у налаштуваннях увімкни «Повідомляти про нові листи».
